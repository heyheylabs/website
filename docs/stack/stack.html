Kubernetes on GKE Autopilot.
Our services run as containers on one managed cluster in Sydney. Google runs the machines, so our time goes into your product, and policy checks every workload before it starts.
Infrastructure as code.
Our cloud is written in OpenTofu. Each change is reviewed in a pull request and applied by CI, never by hand, so every change can be traced and reversed.
A merge queue no one can skip.
Each change passes more than 19,000 automated tests against the latest version before it can reach you. The rule has no bypass, not even for us.
Durable workflows on Temporal Cloud.
Long-running work keeps its place through restarts and failures, so a job is not lost halfway. Our TypeScript workers run against Temporal Cloud’s Sydney region.
Watched, encrypted, kept in Australia.
Cloud Monitoring and Logging watch the platform and alert on admin actions. Our keys sit in Cloud KMS and rotate at least every 90 days. What the platform stores stays in Australia.
